# Arbeitskunde WS 2026/27

Seminar-App für die Arbeitskunde im Studiengang Berufliche Bildung (Universität Bayreuth / Staatliche Berufsschule I Bayreuth).
Entwickelt von Jan Hacker für die Universitätsberufsschule Bayreuth.

- `index.html` – die App (läuft über GitHub Pages)
- `demo/` – Demo mit simuliertem Stand zu Beginn von Sitzung 8, ohne Anmeldung und ohne dauerhaftes Speichern
- Gespeichert wird im selben Repository auf dem Zweig `daten` (`data/arbeitskunde.json`). Die Meldungen und der Dozierendenbereich sind darin mit dem Dozierenden-Passwort verschlüsselt. Jede Speicherung ist ein Commit, frühere Stände lassen sich über die History zurückholen.

Einrichtung und Updates: mit der Datei `arbeitskunde-github-hochladen.html`.
